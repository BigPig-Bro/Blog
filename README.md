# 蹄博 · 大猪蹄子博客客户端

一个**本地优先**的博客阅读器，支持 Windows（EXE）与 Android（APK）双端。

## 简介

「蹄博」用于阅读大猪蹄子博客：启动后自动同步文章到本地，离线也能看；支持文章列表、分类导航、搜索、收藏与阅读进度，并内置「约束辅助」方便硬件开发时查阅猪蹄板的排针引脚定义。

## 支持平台

下列以V1.2.0为例说明

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `蹄博 V1.2.0-win.zip` | 解压后运行 `bigpig_client.exe` |
| Android | `蹄博 V1.2.0.apk` | 直接安装到手机（可覆盖安装 V1.0.0） |

## 安装运行

- **Windows**：把 `蹄博 V1.2.0-win.zip` 解压到任意目录，双击文件夹内的 `bigpig_client.exe` 即可运行。
  注意：`data` 文件夹与 DLL 不能删，单独拷贝 exe 无法运行。
- **Android**：将 `蹄博 V1.2.0.apk` 传到手机后安装，授予联网权限即可同步文章；可从 V1.0.0 直接覆盖升级。

## 功能特性

- 原网页有的内容与跳转，客户端都支持

- **客户端额外支持**
  - 主页搜索框：粘贴博客链接直接跳转，输入关键词可搜索正文（exe）
  
  - 读取剪贴板博客链接，自动识别并询问跳转
  
  - 全局搜索，快速定位文章
  
  - 本地缓存：文章自动同步到本地，离线可读
  
  - 收藏与阅读进度记忆
  
  - 约束辅助：EDA 风格排针引脚图、多猪蹄板 / 外设数据、转接板对齐、双外设叠加
  
  - 主题设置：多套主题色、深浅色模式、字体与字号调整
